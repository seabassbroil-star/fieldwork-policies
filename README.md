# fieldwork-policies

Public Terms of Use and Privacy Policy for Fieldwork, a local,
human-reviewed company research assistant.

These pages exist to:

- explain Fieldwork's intended use and mandatory human review;
- disclose its use of Google Places and public company websites;
- explain local storage, retention, deletion, and operator controls; and
- provide a public issue tracker for policy questions.

Published pages:

- Policy home: https://seabassbroil-star.github.io/fieldwork-policies/
- Terms: https://seabassbroil-star.github.io/fieldwork-policies/terms.html
- Privacy: https://seabassbroil-star.github.io/fieldwork-policies/privacy.html

This repository must contain no API keys, application databases, customer
data, or private Fieldwork source. Publication is a release gate, not legal
certification.
